# GPUI desktop migration

The target is a native GPUI desktop client on macOS, Linux and Windows. Android keeps the Expo application and native Canvas terminal. The daemon, provider adapters, terminal workers, wire protocol and stored conversations remain shared.

The existing Electron application stays available during migration. A native window, terminal demo or subset of features does not complete the migration. Switch the desktop entrypoints and packages only after the parity and deployment checks below pass.

The existing desktop UI is the visual specification. Preserve its layout, typography, icons, colors, spacing, control geometry and interaction states pixel for pixel. Use the authored tokens in `packages/app/src/styles/theme.ts` and the existing components as references. Native migration does not authorize a redesign.

Prioritize terminal typing, scrolling, refresh, tab navigation and CPU/memory measurements. Terminal-launched agents are the primary workflow. Embedded Agent conversations follow terminal parity; the complete acceptance matrix still applies before replacing the installed desktop clients.

## Boundaries

- `packages/desktop/native` owns the Rust application. It connects directly to daemon transports; it does not embed the web application or a JavaScript schema runtime.
- The daemon owns agents, PTYs, query replies and persisted data. Closing or upgrading a client never terminates user terminals.
- Native client capabilities describe implemented delivery semantics. Unknown optional wire fields remain accepted. See [protocol compatibility](protocol-compatibility.md).
- Pin GPUI and its platform crate to the same upstream revision and commit the Cargo lockfile. The framework baseline is Zed `v1.26.2`, commit `c4273271092b0287f7d181f616bd5171e0a2f70c`; framework upgrades need all three desktop builds.

## Development

Run `npm run dev:desktop:native` against the local daemon, or set `PASEO_HOME` to an isolated daemon home. An explicit `PASEO_ENDPOINT=ws://host:port/ws` selects a remote TCP endpoint. Credentials from a local home are never sent to an explicit remote endpoint. `PASEO_PASSWORD` supplies remote password authentication.

Use separate Cargo target directories for comparison checkouts. If you share one, run `cargo clean -p paseo-desktop` before switching checkouts and rebuild the native package. Copy and hash each finished executable before captures: a shared top-level artifact can belong to a different checkout even when Cargo reports the selected checkout as fresh.

`cargo run -p paseo-desktop --no-default-features --bin paseo-native-inspect` exercises native discovery, authentication and paginated directory reads without opening a window. It prints counts and host identity, not credentials or transcripts.

Run `npm run sync:desktop:native-ui` after changing authored theme tokens, provider icons, window controls or Markdown presentation. The generated native assets reuse the app's default dark tokens, identity palette, built-in provider vectors, installed Lucide RN geometry and authored window-control component. Conversation geometry comes from the shared Markdown styles, density values and pinned web renderer. The vendored MD4C engine must match the installed pinned enriched-markdown source byte for byte; the same check covers its source hashes, entity data and license. Cargo compiles the vendored C through a small scalar/string bridge without Node at build or runtime. `npm run check:desktop:native` rejects stale output. Native theme selection and custom appearance settings still require migration.

On macOS with only Command Line Tools, pass `--features runtime-shaders` to Cargo. That uses GPUI's native Metal source compilation at application startup. Default distribution builds precompile Metal shaders and require Xcode's Metal tools.

Fresh source snapshots including the vendored Markdown C parser pass native Cargo checks and ten focused history tests on macOS and Windows. Mac local checks use `runtime-shaders`; Windows uses the MSVC toolchain. These checks do not establish native interaction, packaging or pixel parity on either platform.

The crates.io `gpui` 0.2.2 artifact predates the platform split in the current upstream source. Use the pinned Git pair rather than mixing the published crate with a newer platform backend. A mapped native window alone is not rendering evidence. The pinned baseline has now drawn the directory and terminal in isolated Linux QA; hardware rendering and the other desktop platforms still require interaction checks.

Native terminal checks use isolated daemons and real PTYs:

- [Input and lifecycle](qa-evidence/gpui-native-linux/validation.json): OS keyboard input, SGR wheel reports, and the same retained terminal after closing and reopening the client.
- [Tab retention](qa-evidence/gpui-native-terminal-retention/validation.json): hidden live output, bounded eviction, delayed binding with committed input, authoritative terminal removal, opening timeout/retry and late ownership replies. Ten tab switches use two subscriptions instead of eleven and retain the scrolled canvas exactly.
- [Text clipboard and drag selection](qa-evidence/gpui-native-terminal-selection/validation.json): OS clipboard readback, forward/reverse and rectangular model selection, selection retained across terminal tabs, Ctrl+C copy versus interrupt, and xterm-matched text paste bytes. Selection colors come from the authored theme. Text-paste oracle freshness is checked against the installed xterm source.
- [Pointer input](qa-evidence/gpui-native-terminal-mouse/validation.json): xterm-oracle checks for X10, VT200, drag/hover, SGR and pixel modes, plus actual PTY bytes for buttons, wheel, forced local selection, tab isolation and cold replay. The observer discards OSC/DCS payloads without allocating a second copy. Legacy high-bit reports need a raw-byte host input lane; the current UTF-8 lane shows an explicit error instead of corrupting them. Shared worker replay-mode edge cases remain unresolved in the evidence.
- [Grid projection](qa-evidence/gpui-native-terminal-grid/validation.json): direct borrowed-grid painting, zero allocations in the measured grid-projection stage, and six whole-window captures with zero changed pixels against the previous native build. Actual OS input, live resize and retained-tab navigation also pass. Four terminal-model tests pass on Linux, macOS and Windows.
- [Glyph preparation](qa-evidence/gpui-native-terminal-glyphs/validation.json): bounded reuse of complete shaped cells avoids repeated text-system calls. Hiding a terminal releases those shapes; long combining sequences still render completely without entering the cache. Real font shaping, budget/eviction checks and nine unchanged native window captures cover this path. The optimized preparation benchmark improves, while adjacent debug/software-rendering CPU and RSS samples do not establish an overall improvement.
- [Theme and grid alignment](qa-evidence/gpui-native-terminal-theme/validation.json): the original app terminal runtime supplies the reference. Default palette, font stacks and code size come from authored sources; system fonts are resolved before bundled fallbacks are registered. Pixel-derived color cases, daemon replay dimensions and actual pointer records cover the grid. Terminal-region differences decrease, while text rasterization and full visual acceptance remain unresolved.

The cursor projection now preserves application-selected shape, blink and wide-cell width. Focused block cursors use the authored accent instead of the underlying glyph styles; inactive cursors use the original outline. Blink work stops on hidden panes, blur and the original idle deadline. Focused model and geometry tests pass on all three desktop platforms. Linux private-window checks match bar/underline/outline edge pixels, exercise blink and retained-tab reactivation, and retain all PTYs on close. Glyph-containing cursor crops still differ from Electron; neither these edge checks nor platform compilation establishes full visual or interaction acceptance.

Native subscriptions require the host's `ownedSubscriptions` capability. Host-assigned IDs keep late snapshots from replacing another workspace's inventory. Retaining recent terminal buffers trades bounded resident memory for less replay work. The projection benchmark measures one stage; GPUI shaping, glyph rendering and complex combining-text materialization still have their own costs. The adjacent process samples use a debug build and software rendering, so they do not establish hardware latency, CPU or memory acceptance. The captures preserve existing native drawing, including its grapheme and fallback limitations. Native copy still drops explicit trailing spaces on hard line breaks because the Alacritty cells do not distinguish them from untouched blanks. The clipboard comparison records this mismatch; complete xterm copy fidelity, word/line gestures, drag autoscroll and context menus remain pending. Full terminal fidelity and Electron pixel parity remain pending. Mac and Windows evidence covers compilation and core tests; native interaction there still needs verification.

Use isolated test projects and homes. Do not type into live user agents. Compare the same retained workspace and workload before claiming a performance improvement.

Capture the reference and native client against the same isolated daemon and data. Cover empty, idle, running, attention, selected, hovered, pressed, disabled and open-menu states. Fix the viewport, device scale, theme, fonts, sidebar widths and scroll position. Keep image diffs as evidence. Mask only recorded nondeterministic regions such as a timestamp or spinner angle; do not hide geometry or text differences behind a broad similarity threshold. Framework text rasterization differences remain explicit unresolved evidence until checked on that desktop OS.

The native keyboard encoder has focused regressions for application cursor mode, modified arrows, function keys, control punctuation and native IME ownership. These do not cover Kitty key events, operating-system IME interaction or native rendering; terminal acceptance remains pending until those paths are exercised.
